# 프리마 아키에스

> 괴수가 몰려오는 대협곡 발리스 마그나의 최전선 요새를, 사령관이 직접 싸우며 지켜 내는 웨이브 방어 게임

- 학번 / 이름: 202370020 / 재원
- 저장소: https://github.com/(내아이디)/my-game
- 플레이: https://(내아이디).github.io/my-game/

## 게임 소개

인간의 땅과 괴수의 땅 사이에는 어떤 군단도 넘지 못하는 산맥이 있고, 길은 대협곡 발리스 마그나 하나뿐이다. 서로를 잡아먹으며 쇠퇴하던 괴수들이 마침내 총력전을 시작했고, 플레이어는 요새 프리마 아키에스의 사령관이 되어 15웨이브 동안 성벽을 지킨다.

- 사령관은 전장에 직접 나가 괴수를 베고, 괴수가 떨어뜨린 정수를 주워 온다
- 정수로 성벽 위 병사를 배치하고 강화한다
- 성벽이 무너지면 패배, 15웨이브의 괴수왕을 쓰러뜨리면 승리

### 지금 버전의 규칙 (6주차)

- 15웨이브. 웨이브마다 나올 괴수가 정해져 있고, 모두 쓰러뜨리면 8초 숨 고르기, 5·10웨이브 뒤에는 30초 정비 시간이 온다. 15웨이브를 넘기면 승리
- 휴식 중에만 성벽 위 빈자리를 눌러 병사를 배치한다 (궁수 15, 노포 35). 같은 자리를 다시 누르면 강화 (최대 3단계). "웨이브 시작"으로 휴식을 건너뛸 수 있다
- 정비 시간에는 상점이 열린다: 성벽 수리, 사령관 회복, 병사 훈련, 자리 확장
- 괴수를 쓰러뜨리면 경험치가 오르고, 레벨업하면 특전 셋 중 하나를 고른다. 스킬 습득(수확, 포효, 광폭화)도 특전으로 나오고 Q·E 두 칸에 들어간다
- 마우스를 누르고 있으면 마우스 쪽으로 계속 벤다. 괴수끼리, 사령관과 괴수끼리는 겹치지 않고 밀려난다. 대시 중에는 뚫고 지나간다
- 갑각 짐승은 보호막을 두르고 나온다. 베기는 보호막부터 깎고, 병사의 화살은 보호막에 막힌다
- 6웨이브부터 정수 포식자가 나와 바닥의 정수를 먹는다. 다섯 개를 먹으면 결정 포식수로 진화해 사령관을 노리는 빔을 쏜다 (피하면 성벽 체력 1/3). 차징 중 보호막을 깨면 취소된다
- 사령관 체력이 0이 되면 4초 동안 쓰러졌다가 성벽 앞에서 다시 일어난다
- 괴수가 성벽에 닿으면 성벽 체력이 깎이고, 0이 되면 게임 오버. 점수는 처치한 괴수 수

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 마우스 | 조준 |
| 클릭 (누르고 있기) | 베기 |
| Space / Shift | 대시 |
| Q / E | 스킬 |
| 1 / 2 / 3 | 특전 고르기 (클릭도 가능) |
| 클릭 (휴식 중) | 병사 배치·강화, 상점 |
| R | 게임이 끝난 뒤 다시 시작 |

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 게임을 그릴 캔버스(720×1280 세로 화면) |
| `style.css` | 어두운 배경, 캔버스를 화면 가운데 배치 |
| `script.js` | 게임 전체 (상태, 입력, 게임 루프, 그리기) |
| `images/` | 배경, 성벽, 테두리 어둠, 사령관, 괴수, 정수 이미지 |
| `기획서.md` | 게임 기획서 (3장) |
| `회고.md` | 주차별 작업 회고 |
