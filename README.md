## 게임 아이디어
1장에서 낸 아이디어 3개 중 **프리마 아키에스** (PRIMA ACIES, 탑다운 핵앤슬래시 디펜스)로 만들기로 했습니다.

- 아이디어 기획 단계에서 세 가지 중 가장 구체적으로 기획한 아이디어입니다.
- 웹페이지에서 플레이하는 게임이라는 특성을 생각했을 때 가장 적합하다고 판단했습니다.

나머지 아이디어:

- **어크로스 더 프론트라인** (ACROSS THE FRONTLINE): 횡스크롤 전선 돌파
- **MYTHIC RUN**: 라마야나 기반 러너
